# Noemis Freunde

Eine Lernwelt fürs iPad für die Grundschule (Klasse 1 bis 4, Niedersachsen): Mathe, Deutsch, Englisch, Spanisch, Sachunterricht, Allgemeinwissen und Kunst, dazu eine Leseecke, eine Spielhalle und viele kleine Extras. Mit Lumi, einem kleinen Pinguin, der durch alles führt.

## Starten

1. Den Link zu dieser Seite in Safari öffnen.
2. Beim ersten Start fragt die App nach dem Namen des Kindes, ob es ein Mädchen oder ein Junge ist, nach einem Tierbild und nach der Klasse.
3. In Safari auf „Teilen“ und dann „Zum Home-Bildschirm“ tippen. Dann startet die Lernwelt wie eine App und läuft auch ohne Internet.

Neue Versionen kommen von allein, sobald das iPad beim Start Internet hat.

## Daten: alles bleibt auf dem Gerät

Alles, was das Kind macht (Name, Fortschritt, Tagebuch, Bilder, Freundebuch, Aufnahmen), speichert die App nur auf dem eigenen Gerät, im Speicher des Browsers. Die App schickt nichts an einen Server, auch nicht an den, der sie gebaut hat oder hier bereitstellt. Es gibt kein Konto, keine Werbung, keine Statistik und nichts, was von fremden Servern nachgeladen wird.

Beim Öffnen lädt der Browser nur die App selbst von GitHub herunter. GitHub sieht dabei wie jeder Webserver technische Verbindungsdaten, aber keine Inhalte aus der App. Wer die App bereitstellt, hat darauf keinen Zugriff.

Die App sagt das auch selbst, damit es niemand überliest: beim ersten Start auf einer eigenen Seite, die man mit „Verstanden“ bestätigt, danach immer als Leiste oben auf der Startseite (ein Tipp darauf zeigt alles wieder), im Elternbereich und überall, wo das Kind schreibt, malt oder aufnimmt.

Wichtig: Werden die Websitedaten in Safari gelöscht oder wird die App vom Homebildschirm entfernt, sind auch die Daten weg. Im Elternbereich (unten auf der Startseite „Für Eltern“) gibt es deshalb eine Sicherung als Datei zum Aufheben und Zurückholen. Diese Datei verlässt das Gerät nur, wenn ihr sie selbst irgendwo speichert oder teilt.

## Elternbereich

Dort lassen sich Klasse, Schulthema der Woche, Englisch ab Klasse 1, Vorlesestimme, Lernwörter, Testtraining vor einer Klassenarbeit und „Mama oder Papa liest vor“ (eigene Gutenachtgeschichten aufnehmen) einstellen.

Spanisch: Der Kurs „Mi curso ALCE“ (A2) läuft dienstags von allein mit. Wer nicht in diesem Kurs ist, kann die Spanischwelt trotzdem ganz normal nutzen.

## Dateien

Die ganze App steckt in `index.html`. Dazu gehören `sw.js` (damit sie ohne Internet läuft), `manifest.webmanifest` und die Symbole für den Homebildschirm.
