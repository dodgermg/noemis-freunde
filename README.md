# Noemis Freunde

Eine Lernwelt fürs iPad für die Grundschule (Klasse 1 bis 4, Niedersachsen): Mathe, Deutsch, Englisch, Spanisch, Sachunterricht, Allgemeinwissen und Kunst, dazu eine Leseecke, eine Spielhalle und viele kleine Extras. Mit Lumi, einem kleinen Pinguin, der durch alles führt.

## Starten

1. Den Link zu dieser Seite in Safari öffnen.
2. Beim ersten Start fragt die App nach dem Namen des Kindes, ob es ein Mädchen oder ein Junge ist, nach einem Tierbild und nach der Klasse.
3. In Safari auf „Teilen“ und dann „Zum Home-Bildschirm“ tippen. Dann startet die Lernwelt wie eine App und läuft auch ohne Internet.

Neue Versionen kommen von allein, sobald das iPad beim Start Internet hat.

## Daten

Alles, was das Kind macht (Sterne, Münzen, Tagebuch, Bilder, Aufnahmen), bleibt nur auf diesem iPad. Die App verschickt nichts, hat kein Konto, keine Werbung und lädt nichts von fremden Servern nach. Wie jeder Webserver speichert GitHub beim Abruf der Seite technische Zugriffsdaten.

Im Elternbereich (unten auf der Startseite „Für Eltern“) gibt es eine Sicherung als Datei zum Aufheben und Zurückholen.

## Elternbereich

Dort lassen sich Klasse, Schulthema der Woche, Englisch ab Klasse 1, Vorlesestimme, Lernwörter, Testtraining vor einer Klassenarbeit und „Mama oder Papa liest vor“ (eigene Gutenachtgeschichten aufnehmen) einstellen.

Spanisch: Der Kurs „Mi curso ALCE“ (A2) läuft dienstags von allein mit. Wer nicht in diesem Kurs ist, kann die Spanischwelt trotzdem ganz normal nutzen.

## Dateien

Die ganze App steckt in `index.html`. Dazu gehören `sw.js` (damit sie ohne Internet läuft), `manifest.webmanifest` und die Symbole für den Homebildschirm.
